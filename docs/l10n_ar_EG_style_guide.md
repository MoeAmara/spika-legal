# Spika — دليل العامية المصرية (`ar_EG`)

مرجع للنبرة في نصوص التطبيق. الهدف: عامية مصرية محترمة — مش فصحى ثقيلة ومش عامية مبالغ فيها.

## نعم

- "سجّل معاملة" / "ضيف معاملة"
- "فاتورة اتأخرت"
- "رصيدك" / "إجمالي الرصيد"
- "كمل" / "تمام" / "احفظ" / "ارجع"
- "مفيش معاملات لسه"
- "عديت الميزانية"
- "حصل مشكلة" بدل "العملية فشلت"

## لا

- "يُرجى إدخال المبلغ" (فصحى رسمية)
- "تمت العملية بنجاح"
- "يا معلم" / "يا باشا" (عامية زيادة)
- "الرجاء الانتظار"

## الأزرار

- فعل أمر قصير: 1–3 كلمات
- "احفظ" مش "حفظ"
- "مسح" للحذف في السياق المحادثي

## الأخطاء

- اشرح المشكلة + اقترح خطوة تالية
- مثال: "مستخدم في ٣ معاملات. غيّره الأول."

## المبالغ والاتجاه

- المبالغ تُعرض **RTL** في الواجهة العربية (رقم ثم رمز العملة)، و**LTR** في الإنجليزية
- أرقام ومبالغ عربية: أرقام هندية-عربية (٠–٩) بخط Lama؛ بدون فواصل آلاف؛ العلامة العشرية فصلة دائمًا (مثل `١٢٣٤,٥٠`)
- الوزن العادي أثقل قليلًا (Medium بدل Regular) مع مقياس حجم متطابق مع الإنجليزية
- خط الإنجليزية (عناوين، نص، أرقام): **Bricolage Grotesque** (`SpikaBricolage`)
- أكواد العملات في العربية: اختصارات عربية (مثل ج.م، ر.س، دولار) بخط Lama
- صفحة أسعار الصرف: أسماء العملات (مش الأكواد) + "أسعار كل عملة"

## مفاتيح ARB

- واجهة: `lib/l10n/app_*.arb`
- كلمات الأسبوع: `weekWord_{id}_label` / `weekWord_{id}_explanation`
- الفئات المدمجة: `categoryExpenseFood` وغيرها عبر `builtin_key`
